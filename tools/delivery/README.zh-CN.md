# OpenPLC 工装 —— 怎么用

English: `README.en.html`

这个文件夹就是全部，不需要装开发环境。

## 一、先装一个软件

**STM32CubeProgrammer** —— ST 官网免费下载，装上就行。

<https://www.st.com/en/development-tools/stm32cubeprog.html>

⚠️ **不是** STM32CubeIDE。要的是那个几十兆的烧录器，不是一整套开发环境。ST-Link 的驱动跟着它一起装好。

## 二、双击 `start.cmd`

只有这一个入口，双击它会出菜单：

```
    1) 烧固件进板子      (先接好 ST-Link，板子上电)
    2) 打开测试面板      (先接好 RS232 控制口)
    3) 两样都做          (先烧，再打开面板)
    4) 看使用说明（中文）
    5) Read the guide (English)
    0) 退出 / Quit
```

输数字回车就行。做完回到菜单，可以接着做下一件。

## 三、测端口

菜单选 2（或 3），浏览器会自己打开一个页面。

1. 左上「连接」：选板子的 **RS232 控制口**（一般是插在电脑上那个 USB 转串口，端子 C05/C06），点「连接」
2. 左边选测试类型：**研发测试**是一项一项人工测；**工装完整测试**里勾功能、老化、安规、用户级，配好后一次跑完
3. 研发测试里，中间选一个端口，右边出现它的测试项卡片：每张写着「测什么 / 要接什么 / 什么算过」
4. 勾好要测的卡片，点右上角「开始」。要人量或要人看的，会弹出带 🍍 的提问，照着填就行

**不用记命令。** 要接对端的项（USB、网口、RS485、CAN、标准机），先在左上「连接」里把那一样接上。

⚠️ 面板打开后会多一个黑窗口，**别关它**，关了面板就停。测完再关。

⚠️ 旁边那个 `plans` 文件夹别删 —— **每一项「什么算过」都写在里面**，删了面板就只能给读数、给不出结论。

⚠️ `stage6` 文件夹也别删 —— 第 6 步（用户级功能测试）要用里面的 bootloader、IAPTool 和 demo。

## 四、要万用表的地方

模拟输出、DO 带负载这类板子自己读不回来的值，面板会停下来问你万用表读到多少，填进去它来判。只在研发测试里问；工装完整测试由标准机读，不问人。

模拟量校准只在**研发测试**里：逐点填万用表读数，面板拟合出每一路的 k、b，存在本机，再用 ST-Link 烧进板子。

## 五、在 Linux 上用

同一个文件夹，Linux 的文件也在里面，用法和上面一样，只有下面几处不同。

1. **入口**：在终端里进到这个文件夹，运行 `bash start.sh`，出来的菜单和 `start.cmd` 一样。别双击它，双击多半只会当文本打开。
2. **装 Linux 版 STM32CubeProgrammer**：同一个网址下载。装在默认位置（`~/STMicroelectronics/STM32Cube/STM32CubeProgrammer` 或 `/usr/local/STMicroelectronics/STM32Cube/STM32CubeProgrammer`），或者把它的 `bin` 放进 PATH，菜单和面板都能找到它。
3. **串口权限**：当前用户要在 `dialout` 组里，不然打不开串口。运行 `sudo usermod -aG dialout $USER`，退出登录再进来才生效。
4. **KNX USB 接口**：在 Linux 上走 `/dev/hidraw*`，默认只有 root 能打开。要加一条 udev 规则放开它，例如在 `/etc/udev/rules.d/99-knx-usb.rules` 写 `SUBSYSTEM=="hidraw", ATTRS{idVendor}=="<厂商号>", MODE="0666"`（厂商号用 `lsusb` 查），再拔插一次接口。
5. **面板在终端里运行**：选 2（或 3）之后，面板就在 `start.sh` 那个终端里跑，按 Ctrl+C 停掉面板、回到菜单。测完再按。
