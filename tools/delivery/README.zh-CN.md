# OpenPLC 工装 —— 怎么用

English: `README.en.html`

这个文件夹就是全部，不需要装开发环境。

## 一、先装一个软件

**STM32CubeProgrammer** —— ST 官网免费下载，装上就行。

<https://www.st.com/en/development-tools/stm32cubeprog.html>

⚠️ **不是** STM32CubeIDE。要的是那个几十兆的烧录器，不是一整套开发环境。ST-Link 的驱动跟着它一起装好。

## 二、双击 `start.cmd`

只有这一个入口，双击它会出菜单：

```
    1) 烧固件进板子      (先接好 ST-Link，板子上电)
    2) 打开测试面板      (先接好 RS232 控制口)
    3) 两样都做          (先烧，再打开面板)
    4) 看使用说明（中文）
    5) Read the guide (English)
    0) 退出 / Quit
```

输数字回车就行。做完回到菜单，可以接着做下一件。

## 三、测端口

菜单选 2（或 3），浏览器会自己打开**工装测试大屏**：一个方块一个工位。左边「接线（按工位）」列出每个工位的线，点一个工位打开它的接线登记，在那里给控制口 RS232、RS485 / CAN 转换器、标准机、ST-Link 点「换」选好；方块下面「＋ 增加工位」加一个。板子插上后方块自己往下走：没有工装固件或版本旧时点「烧写」，接好线后自动跑 ① 功能测试，方块上写正在测第几项；不合格时板上 LED3 亮，点「继续」重做这一步或「重新」从 ① 开始。点方块进这块板的单板页，每一步一个页签，逐项列出参数、判据、读数和结果，最后是出厂单。① 过了以后 PortTool 把老化任务写进板子，方块显示「拔线拿去高温柜」；板子在高温柜里通电就自己跑、自己计时（LED3 慢闪），插回来自动读结果做 ③。每一步测什么、老化测哪几项跑几小时，在左上角「模板」里配：可以建几个模板，保存一次版本加 1，「用这个模板」之后接上的板子按它测。右侧列出在高温柜里的板子和所有工位最近的提交记录。

左上角「测试类型」选「研发测试」打开下面说的测试面板，同一个地方选「工装测试」回到大屏；选哪个下次打开还是它。面板顶上点「使用说明」，有带截图的详细说明，截图上标着每一步点哪里。

左边「接线」一栏：研发测试就是 1 号工位，每根线接在哪个口按 1 号工位的接线登记，点这一栏就打开登记改口。最上面「电脑上看到的板子」列出电脑上看到的每块板和上面的固件，不是当前工装固件的点「烧写」（经 1 号工位的 ST-Link）。

1. **第一步：连接控制口**：在接线登记里给「控制口 RS232」选板子的 **RS232 控制口**（一般是插在电脑上那个 USB 转串口，端子 C05/C06），不知道是哪个就点「自动找」。之后板子一插上、工装固件在跑就自动连上，不用点「连接」。蓝牙串口不列出来
2. **第二步：连接其余端口**：只接要测的端口用到的，用不到的不用管。每一行左边的圆点是绿的就是连上了，灰的就是没连上；鼠标停在灰的那一行上能看到原因，旁边点「重试」再试一次。每一行只显示简短的值（口名、IP、「已插上」），鼠标停上去看完整的。左边这一栏和研发测试最右的日志栏，拖它们的边能调宽度，下次打开还是这个宽度。这一块按机器分组：被测板、标准机、电脑上的设备各一块，组名做小标题。这几行只显示接线登记选的口，没有下拉、没有「接上」按钮：测试开始时才打开这个口，测完就关。RS485、CAN 连上后会自动识别、自动选好，认不出来再在接线登记里选
   - 测试报「串口被占」时，点右边的「**强制释放端口**」：停掉正在跑的测试、关掉面板开着的口；还关不掉的，会写明是哪个口被别的程序占着
3. **研发测试**一项一项测，可以选时长长时间跑；DI、DO、AI、AO、继电器的端口页头选「接法」：互相连（接回环线束，板子自己判）、标准机、其他机器（给高低温箱、EMC 用：DI、AI 按设定值判，DO、AO、继电器只按设定值输出，由外部仪器看）、人工，DI、DO、继电器共用一个，AI、AO 共用一个；测继电器前先确认 DI、DO 是好的。工装测试在大屏上跑（左上角「测试类型」）：功能、用户级里 DI、AI、DO、继电器可以用标准机测，也可以用外部仪器（每一项写着用哪种）；接线登记里把标准机选「不用」时，要标准机的项默认不勾，照样能开始。日志里每条板子发来的数据下面跟一行译文，写明每个数是什么、带单位
4. 研发测试里，中间选一个端口，右边出现它的测试项卡片：每张写着目标、测试方法（照着一步步做）、要接什么和什么算过
5. 勾好要测的卡片，点「开始」。要人量或要人看的，会弹出带 🍍 的提问，照着填就行

**不用记命令。**

⚠️ 研发测试的「时钟（晶振）」页的「晶振驱动档与起振余量」会换晶振的驱动档。选「全部」跑完（或按「停止」）会自己切回中低档；**只选一个档时，换的档会一直留在板子上，复位也不变**，要回出厂档点「恢复出厂档位」（或再选「全部」跑一次）。

⚠️ 有些「什么算过」的数（例如晶振的偏差上限、漂移上限、起振用时上限）出处还没核实，面板给的是默认值，卡片上写着默认值从哪来。**你可以直接在卡片上改，清空就只记录不判。**

⚠️ 面板打开后会多一个黑窗口，**别关它**，关了面板就停。测完再关。

⚠️ 旁边那个 `plans` 文件夹别删 —— **每一项「什么算过」都写在里面**，删了面板就只能给读数、给不出结论。

⚠️ `stage6` 文件夹也别删 —— 第 6 步（用户级功能测试）要用里面的 bootloader、IAPTool 和 demo。

## 四、要万用表的地方

模拟输出、DO 带负载这类板子自己读不回来的值，面板会停下来问你万用表读到多少，填进去它来判。DO 带负载按卡上的「压降上限」判（默认取测试方案里的值，可以改，清空就只记录不判）。只在研发测试里问；工装完整测试由标准机读，不问人。

模拟量校准只在**研发测试**里：逐点填万用表读数，面板拟合出每一路的 k、b，存在本机，再用 ST-Link 烧进板子。

## 五、在 Linux 上用

同一个文件夹，Linux 的文件也在里面，用法和上面一样，只有下面几处不同。

1. **入口**：在终端里进到这个文件夹，运行 `bash start.sh`，出来的菜单和 `start.cmd` 一样。别双击它，双击多半只会当文本打开。
2. **装 Linux 版 STM32CubeProgrammer**：同一个网址下载。装在默认位置（`~/STMicroelectronics/STM32Cube/STM32CubeProgrammer` 或 `/usr/local/STMicroelectronics/STM32Cube/STM32CubeProgrammer`），或者把它的 `bin` 放进 PATH，菜单和面板都能找到它。
3. **串口权限**：当前用户要在 `dialout` 组里，不然打不开串口。运行 `sudo usermod -aG dialout $USER`，退出登录再进来才生效。
4. **KNX USB 接口**：在 Linux 上走 `/dev/hidraw*`，默认只有 root 能打开。要加一条 udev 规则放开它，例如在 `/etc/udev/rules.d/99-knx-usb.rules` 写 `SUBSYSTEM=="hidraw", ATTRS{idVendor}=="<厂商号>", MODE="0666"`（厂商号用 `lsusb` 查），再拔插一次接口。
5. **面板在终端里运行**：选 2（或 3）之后，面板就在 `start.sh` 那个终端里跑，按 Ctrl+C 停掉面板、回到菜单。测完再按。
